WEBSITE VISIT DICE SIMULATOR

Requirements:
- Java 17 or newer (uses the built-in com.sun.net.httpserver module)
- No external libraries or frameworks

How to run:
1. Put Main.java, index.html and style.css in the same folder.
2. Open a terminal in that folder.
3. Compile: javac Main.java
4. Run: java Main
5. Open http://localhost:8080 in your browser.
6. Click "Roll dice 100,000 times".

The six websites are assigned to dice faces 1 through 6. The Java backend
performs 100,000 random rolls and displays the count and percentage for each.

Important:
These are simulated selections, not real visits or actual website analytics.
The website names are taken from the supplied screenshot and are not verified.
